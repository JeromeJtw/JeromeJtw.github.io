# 摄影

<span class="status-line">长期兴趣领域 · 内容待实践后发布</span>

本领域用于记录摄影知识、拍摄实践和作品复盘。网站只保存适合 Web 展示的压缩图片；RAW 原片和大量全尺寸照片保留在本地或专门存储中。

## 计划结构

- 曝光与测光；
- 焦距、景深与镜头语言；
- 构图与视觉重心；
- 自然光与人工用光；
- 色彩与影调；
- 拍摄计划和现场工作流；
- 选片与后期处理；
- EXIF、拍摄参数和作品复盘；
- 精选摄影作品集。

公开作品前会检查版权、肖像权、位置隐私和素材授权。
