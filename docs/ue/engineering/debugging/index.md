# Bug 与排障记录

问题记录关注排查能力，而不是只保存最终解决命令。

## 每个问题必须包含

1. 现象和复现条件；
2. 影响范围；
3. 已排除方向；
4. 根因；
5. 修复或处理决定；
6. 验证证据；
7. 对后续工程的影响。

## 分类

- 构建与工具链；
- UObject、生命周期与 GC；
- Gameplay、输入和动画；
- GAS、AI 与网络；
- 资源、Cook 与发布；
- 性能、内存与加载；
- 版本差异和资产许可。

公开版本会移除本机敏感路径、凭据和不适合对外展示的信息。
