# 面试题与项目复盘

这里不会堆积脱离项目的背诵答案。每个问题都要连接到 Project Aegis 中的实现、失败实验、日志、Trace 或设计取舍。

## 问题结构

1. 先用一句话给出结论；
2. 解释 UE 机制和边界；
3. 给出 Project Aegis 中的实际证据；
4. 说明替代方案与取舍；
5. 回答常见追问。

## 主题索引

- Target、Platform、Build Configuration 与模块；
- UObject、反射、CDO、GC 与对象指针；
- Gameplay Framework 和生命周期；
- 输入、相机、动画和战斗；
- GAS、AI 与网络；
- 资源、测试、性能与源码阅读；
- 项目架构、故障复盘和团队协作。
