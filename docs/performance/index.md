# Unreal Insights 性能案例

本栏目将在性能课程开始后记录真实 Trace 和优化案例，目前不预填未经验证的结论。

## 案例模板

- 场景与设备；
- 性能预算和基线；
- Trace 捕获方式；
- Game Thread、Render Thread、GPU 或加载瓶颈；
- 假设与验证实验；
- 优化前后数据；
- 画质、内存、复杂度和维护成本取舍；
- 回归测试方式。

::: warning 数据要求
性能结论必须绑定固定场景、硬件、构建配置和采样方法，不能只凭编辑器中的一次 FPS 波动判断。
:::
