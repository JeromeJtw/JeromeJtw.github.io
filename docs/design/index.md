# 系统设计文档

这里记录 Project Aegis 中经过实现与验证的系统设计。设计文档不会预先虚构最终架构，而是随工程演进保存问题、约束、备选方案、决策和验证结果。

## 计划收录

- 模块与依赖边界；
- Gameplay Framework 职责图；
- 输入、移动与相机数据流；
- 战斗、动画与 GAS 链路；
- AI 感知、决策和导航；
- Authority、Ownership 与复制边界；
- 资源加载、SaveGame 和发布流程；
- 测试场景与性能预算。

## 文档完成标准

每份设计至少包含：背景、约束、方案、取舍、数据流或时序图、失败路径、验证证据和关联版本。
